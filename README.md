# Java-basic-projects
Hello! In this repository you could see my progress in writing basic java codes.

1. GroceryStoreReceipt.java - Asks what items you bought and for what price, and then calculates your total receipt.
   - Uses For-loop, If-else condition, and Scanner class.

2. GuardiansCafe.java - A coffee order menu where you could choose your drink, and then calculates your change.
   - Uses For-loop, If-else condition, Logical and Relational operators, Scanner class, Switch statement, and While-loop.  
  
3. MultipleCalculator.java - Allows the user to perform basic calculations: addition, subtraction, multiplication, division, modulo.
   - Uses Do-while loop, If-else condition, Logical and Relational operators, Scanner class, Switch statement, and While-loop.
  
4. SubjectGrading.java - Ask the user what are the subject and there grades. Then displays the average, lowest, and highest scores.
   - For-loop, If-else condition, Scanner, and While-loop.
